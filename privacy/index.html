개인정보 처리방침

약시계 (YakSigye) · 최종 수정: 2026년 5월

간단 요약

약시계는 이메일, 전화번호, 이름 등 어떠한 개인 식별 정보도 수집하지 않습니다. Firebase 익명 인증을 사용하여 계정 없이 이용할 수 있습니다.

1. 수집하는 정보

약시계는 다음 정보를 수집합니다:

  • 익명 식별자: Firebase Anonymous Authentication이 생성하는 랜덤 UID (이름, 이메일, 전화번호 없음)
  • 복약 기록: 사용자가 직접 입력한 약 이름, 복약 시간, 복약 인증 로그 (기기 내 및 Firestore 저장)
  • 페어링 코드: 자녀-부모 연결에 사용되는 6자리 임시 코드 (사용 후 즉시 삭제)
  • FCM 토큰: 복약 알림 발송에 필요한 Firebase Cloud Messaging 기기 토큰 (개인 식별 불가)

수집하지 않는 정보: 이름, 이메일, 전화번호, 위치, 연락처, 사진, 카메라, 마이크

2. 정보 이용 목적

  • 복약 일정 알림 발송 (TTS 음성 + push notification)
  • 자녀-부모 앱 간 복약 상태 동기화
  • 복약 이력 조회 (캘린더 / 달성률)
  • 케어플러스 구독 상태 확인

3. 제3자 제공

수집된 정보는 제3자에게 판매·임대·공유하지 않습니다. 다음 서비스와 기술적으로 연동됩니다:

  • Google Firebase (Firestore, Authentication, Cloud Messaging) — Google 개인정보처리방침 적용
  • Apple App Store / Google Play Billing — 구독 결제 처리 (구독 시)

4. 데이터 보관 및 삭제

  • 무료 플랜: 복약 이력 최근 30일 자동 삭제
  • 케어플러스: 복약 이력 최근 1년 보관
  • 앱 삭제 시 기기 내 데이터 즉시 삭제. Firestore 데이터는 앱 내 '데이터 삭제' 기능 또는 이메일 요청으로 삭제 가능

5. 어린이 개인정보 (COPPA / GDPR-K)

약시계는 13세 미만 아동을 대상으로 하지 않습니다. 13세 미만 사용자의 개인정보를 의도적으로 수집하지 않습니다. 13세 미만 어린이가 데이터를 제공한 것을 인지하는 경우 즉시 삭제 조치합니다.

6. 보안

모든 서버 통신은 TLS 암호화를 사용합니다. Firebase Security Rules를 통해 본인의 데이터에만 접근 가능하도록 제한합니다.

7. 방침 변경

개인정보 처리방침이 변경될 경우 앱 내 알림 또는 본 페이지를 통해 사전 안내합니다. 중요한 변경 시에는 앱 업데이트 시 재동의를 요청합니다.
