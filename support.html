자주 묻는 질문

앱에 가입이 필요한가요?

아니요. 약시계는 이메일·비밀번호 없이 Firebase 익명 로그인으로 자동 시작됩니다. 별도 계정 생성이 필요 없습니다.

자녀 앱과 부모 앱을 어떻게 연결하나요?

1. 자녀 앱 → '가족 추가' → 6자리 페어링 코드 확인
2. 부모 앱 → '자녀와 연결' → 6자리 코드 입력
연결은 1회만 하면 되고, 이후 자동 동기화됩니다.

복약 알림이 오지 않아요

다음을 확인해 주세요:

  • 기기 설정 → 약시계 → 알림 허용 여부
  • 방해금지 모드(집중 모드) 해제 여부
  • 앱이 백그라운드에서 완전 종료되지 않았는지

iOS: 설정 → 약시계 → 알림 → '허용' 켜기

케어플러스 구독을 해지하려면?

iOS (App Store): 설정 → Apple ID → 구독 → 약시계 케어플러스 → 구독 취소
Android (Google Play): Play Store → 내 구독 → 약시계 → 구독 취소

갱신 3일 전(iOS) / 1일 전(Android) 전에 취소하시면 다음 결제 발생 없이 해지됩니다.

내 데이터를 삭제하고 싶어요

앱 내 설정 → '데이터 삭제' 버튼을 이용하거나, 아래 이메일로 요청해 주세요. 7일 이내 모든 Firestore 데이터를 삭제해 드립니다.

TTS 음성이 작동하지 않아요

기기 볼륨 및 무음 모드 해제 여부를 확인해 주세요. iOS의 경우 사이드 스위치(무음 스위치) 및 볼륨 설정을 확인하세요. 앱 재시작 후에도 문제가 지속되면 이메일로 문의해 주세요.
